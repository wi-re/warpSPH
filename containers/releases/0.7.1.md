## Usage

```bash
docker load -i warpsph-0.7.1-amd64.docker.tar.gz
docker run --rm --gpus all -v "$PWD:/work" warpsph:0.7.1 help
```

Transfer the Isambard tar and its checksum to shared storage, extract it alongside
the accepted deployment, and follow its README. Use Python3.11+ for the bundled
verifier (the existing Miniforge Python is suitable). Set `QA_ROOT` to the extracted
release and source its **new** `harness/site-profile.sh`. The profile is marked
`pending-site-qualification`; it does not reuse the previous image's passing
status. Renew single, same-node, cross-job restart and multi-node stages in order.
The previously accepted SIF, profile and results remain untouched.

Build contexts, exact commands, manifests, image inventories, target fingerprints,
qualification receipts and failure evidence are retained with the local artifacts.
